# minime
A me flavoured development workflow

minime is a family of plugins. Each plugin lives in its own top-level directory.

- [`coder/`](coder/): the staged delivery loop (clarify, chart, build, prove, converge, land-learn, routed by deliver). Adopted from [chewcorp/kilo-mms](https://github.com/chewcorp/kilo-mms) at `e86bfeb`, history included. See [`coder/AGENTS.md`](coder/AGENTS.md).
