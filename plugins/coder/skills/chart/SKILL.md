# chart

Optional for one-ticket work. Required for multi-ticket.

Emit ordered tickets with blocking edges, tracer-bullet first. Split by workflow steps, rule variations, entry method, or deferred qualities. Unestimable → split or mark spike with question plus timebox; dependents wait a later iteration. Depth scales with door type: one-way earns scrutiny, two-way earns speed.

Done when every ticket passes INVEST or is a marked spike, and O→R→S traceability has zero orphans.
