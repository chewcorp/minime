# prove

Name the proof before work. Show proof, not summary.

Check the real artifact: run it, read the value, inspect the diff. Prefer a deterministic script a reviewer can rerun. Suspect the observation method before the system. Perf claims carry limiter, median plus range, verdict faster/slower/no-diff/inconclusive. Each unit ends in a check.

"Tests passed" or "agent said so" is not done.
