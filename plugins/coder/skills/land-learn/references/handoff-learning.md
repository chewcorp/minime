# Handoff and learning

Keep declined blockers visible with their evidence and the reason for declining.
Include open decisions and checks that did not run. The author's explanation
helps the human assess the change; it does not replace independent approval.
Do not claim an independent briefing unless a separate reader actually made it.

Persist a lesson only when, without it, someone reading the final code, tests
and documentation would likely repeat the mistake or repeat substantial
investigation. Update a matching reference first. Store detail where the next
relevant task can discover it, not in every agent's always-loaded context.
Do not add a mandatory gate merely because a lesson can be automated.
