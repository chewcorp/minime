## Verdict (this case, this model)

**Baseline for optimisation, not a keep/cut decision. On F8 the current
payload produced 4/4 passing, path-canonicalising fixes (no-payload
reference: 2/4 and 1/4). Variants must not regress this; a variant that
brings back string-compare guards fails F8.**

For scale: the canonical-fix split of 4/4 vs 1/4 gives a one-sided Fisher
exact p ≈ 0.07, and the pass split of 4/4 vs 2/4 gives p ≈ 0.21.

Known confounds:
- The absent prompt carries an extra note line.
- The subject is a single free model.
- macOS and Linux give different oracle scores, as noted above.

Model pinning: these runs predate the tracer's agent pin. The fixture's
project `kilo.json` pins `planner` and `advisor` to `kilo-auto/frontier`, but
none of the transcripts invoked either one. Every model call was
`kilo-auto/free`. Later runs pin every listed agent to `$MODEL` through
`KILO_CONFIG_CONTENT`, and refuse to start if the resolved config shows any
other model.
